# 经验摘要（速查）

> 详细论证见各专题文档。本页只收「下次别再踩」的短句。

1. **能聊 ≠ 能搜**  
   ChainFuel/OpenRouter 只管 completions；WebSearch 在 openrouter 下已改本地 HTTP，不再打 Cursor 云。

2. **黄三角 + login rejected**  
   先查 provider 是否仍走 Cursor 工具；openrouter 应走 `local-web-tools`。不要先重装 Chrome。

3. **mason1 有 clash（:7890），不是 Mac ClashX**  
   进程在 ≠ 海外 TLS 通；节点坏时全局代理会拖死 ChainFuel，必须 `NO_PROXY`。

4. **asar 曾写死 openrouter.ai**  
   改 env 不够，要打安装包或确认 strings 里已是 chainfuel。

5. **Disk Saver 是磁盘压力 Agent**  
   88% 会反复出现；聊天请 `+` 新会话。

6. **SSH 用 `mason1` 别名**  
   直连 `31.58…:6002` 常失败；配置走中转。

7. **health 用 `/health` + Bearer**  
   `GET /` 404 正常。

8. **官方 Grok Bot 与 TCD 隔离**  
   官方只用 `Grok Bot.app` + `~/Library/Application Support/Grok Bot`。TCD 只用 `launch-mason1-computer.sh`（`grok-bot-tcd.app` + `Grok Bot Reconstructed Intel`）。不要从 Finder 点 TCD/Intel 包；不要跑 `launch-intel-macos.sh`。两套不要同时占 1340。

9. **删除用 mv 归档**  
   mason1 清盘先授权再动大目录。

10. **文档只写本仓库 `docs/`**  
    进度更新 `PROGRESS.md`；案例放 `cases/`。
